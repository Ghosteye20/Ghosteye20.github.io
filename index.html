Small tools for
everyday hassles.

Some everyday tasks aren't hard, just repetitive or fiddly. Filling the same sheets, sending emails one by one, coming up with yet another password.

So whenever I spot one of these chores, I try to build a small tool that does it for me. This page is where I keep them all. If one saves you an hour, it's done its job.

🔁
The problem

Little daily hassles

Re-typing data, sending emails one by one, juggling passwords and browser tabs. Small things that add up.

🛠️
The fix

A simple tool for each

A web app or a Chrome extension, built for one job. Quick to open and easy to use.

✅
The result

Time back

Less effort, fewer mistakes, and more time for the things that really matter.
